### 🤖 Проекты

 - **RadarShield** — подписочный VPN-сервис. FastAPI-лендинг с оплатой через Robokassa, Marzban-маршрутизация, HMAC-токены стабильных подписочных ссылок, Telegram-бот для конфигов и продлений.
  Сайт: https://radarshield.mooo.com · Бот: [@radarshield_bot](https://t.me/radarshield_bot)

 - **Beauty Bianca** — полнофункциональное веб-приложение поверх YClients API: самостоятельная оболочка, повторяющая весь функционал сервиса (журнал записей и календарь, клиенты, касса и финансы, лояльность/сертификаты/абонементы, склад, услуги, расписание мастеров, отзывы, отчёты) и расширяющая его. Offline-first архитектура: YClients полностью зеркалируется локально (12 mirror-таблиц, 22 endpoint'а), интерфейс не зависит от стороннего API; outbox-паттерн с гарантированной доставкой операций обратно в YClients при нестабильной сети. SSE real-time синхронизация, webhook-логирование, дизайн-система. Стек: FastAPI, SQLAlchemy, Alembic, PostgreSQL, HTMX, Tailwind.

 - **StackRadar** — радар вакансий из публичных Telegram-групп. Парсит резюме (PDF), извлекает опыт и навыки, матчит вакансии по профилю и шлёт пользователю только релевантные.

 - **HH Auto-applier** — автоматический отклик на hh.ru. Hunter тянет вакансии по фильтрам, LLM-скоринг релевантности по 6 критериям, генератор сопроводительного под каждую вакансию, follow-up engine с напоминаниями и классификацией HR-переписки.

 - **Интеллектуальный помощник** — персональный Telegram-ассистент: голосовой и текстовый capture в Obsidian-vault, авто-классификация заметок, авто-создание тасок и событий, интеграция с Todoist и Google Calendar через MCP, обработка через Claude API.
